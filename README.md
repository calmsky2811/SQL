# SQL Notes

A cumulative, structured set of SQL notes focused on understanding concepts, writing reliable queries, and revising efficiently.

## Learning approach

Each topic aims to include:
- **Core idea:** what the concept means and why it exists
- **Syntax and examples:** practical SQL examples
- **How it works:** a step-by-step explanation
- **Important distinctions:** concepts that are easy to confuse
- **Pitfalls and edge cases:** common mistakes and qualifications
- **Revision:** concise takeaways and, where useful, a cheat sheet
